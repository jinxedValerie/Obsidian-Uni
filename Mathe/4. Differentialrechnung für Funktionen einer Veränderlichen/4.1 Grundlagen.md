Eine Funktion $f$ heißt in $x_{0}$ #differenzierbar, wenn der #Grenzwert

$\large\lim_{ x \to 0 } \frac{f(x) - f(x_{0})}{x - x_{0}}$
existiert

Der so definierte Grenzwert wird #Ableitung von $f$ in $x_{0}$ genannt. Existiert er für alle $x_{0} \in (a,\;b)$, so heißt $f$ auf $(a,\;b)$ differenzierbar 

**Symbol:** $f'(x_{0}) = \frac{df}{dx}(x_{0})$

### Rechenregeln
