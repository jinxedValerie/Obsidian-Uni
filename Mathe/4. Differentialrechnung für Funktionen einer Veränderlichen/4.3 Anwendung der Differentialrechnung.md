2.  Grenzwerte unbestimmter Ausdrücke ( #Bernoulli-LHospital)


#### #Bernoulli-LHospital 
#Satz/4/15
Falls:
$\lim_{ x \to x_{0} } f(x) = \lim_{ x \to x_{0} } g(x) = 0 \quad\quad\text{"}\frac{0}{0}\text{"}$
oder
$\lim_{ x \to x_{0} } |f(x)| = \lim_{ x \to x_{0} } |g(x)| = \infty \quad\quad \text{"}\frac{\infty}{\infty}\text{"}$

Dann folgt:
$\lim_{ x \to x_{0} } \frac{f(x)}{g(x)} = \lim_{ x \to x_{0} } \frac{f'(x)}{g'(x)}$
falls der rechts stehende Grenzwert existiert

#Bem/4/16
"$0\cdot \infty$":
- zu "$\frac{0}{0}$" mittels $c\cdot d = \frac{c}{\frac{1}{d}}$
- oder zu "$\frac{\infty}{\infty}$" mittels $c\cdot d = \frac{d}{\frac{1}{c}}$
Bei $0^\infty, 1^\infty, 0^0, \infty^0$ kann die Gleichheit $y = \exp(\ln(y))$ verwendet werden um #Satz/4/15 anzuwenden
